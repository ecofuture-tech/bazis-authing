# bazis-authing 2.7.0

Requires Bazis 2.5 and bazis-users 2.9.

## Changes

- The tokens of a request (the bearer token, the query parameter and the cookie
  `BAZIS_AUTH_COOKIE_NAME`) are read by `get_request_tokens` of bazis-users, in its order
  (the query parameter, else the bearer token, else the cookie), instead of a copy of the
  parameters in `AuthStore`, `GET /auth/` and `POST /logout/`. The OpenAPI operations of
  the endpoints with a store declare the bearer token as the security scheme
  `OAuth2PasswordBearer` instead of a header parameter `Authorization`.
- `POST /password/token/` is the token endpoint of bazis-users (`POST
  BAZIS_OPENAPI_TOKEN_URL`) registered under this path instead of a copy of it, and is
  deprecated (removed in 3.0): clients use the token endpoint of bazis-users. The answer
  is the same; the error of wrong credentials is translated, and the operation documents
  the 401.

## Breaking changes

- `AuthStore(...)` takes the tokens of the request as `RequestTokens`
  (`bazis.contrib.users.service`) instead of the three parameters `token_param`,
  `token_cookie`, `token_header`: code that creates a store itself passes
  `AuthStore(RequestTokens(param=store_token))`. A store taken as a dependency
  (`auth_store: AuthStoreTokenRequired = Depends()`) is unchanged.
- `bazis.contrib.authing.service.get_token_header` is removed: use
  `RequestTokens.header` of `get_request_tokens`.
