# bazis-authing 2.4.0

Requires Bazis 2.4.

## Tools and AI agents

- The package ships `AGENTS.md` (setup, the sign-in flows, the security properties, own
  services) and `bazis_manifest.toml` for tools and AI agents (see `docs/agents.md` of
  Bazis).
- New system checks (`manage.py bazis_doctor`), registered by the app: add
  `bazis.contrib.authing` to `BS_INSTALLED_APPS`:
  - `authing.W001`: a module of `BAZIS_AUTH_KINDS` cannot be imported (`GET /auth/` skips
    it silently, e.g. `bazis.contrib.authing.password` instead of
    `bazis.contrib.authing.services.password`);
  - `authing.E001`: the router of a service of `BAZIS_AUTH_KINDS` is not registered, so
    `GET /auth/` fails for anonymous users.
- Dependencies: `bazis>=2.4.0`.
